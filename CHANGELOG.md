# Changelog

## 1.0.2

- Fixed a directory check: no variable shares a name with the JSX helper `h`
- Added a Privacy section to the README
- Added a plugin icon

## 1.0.1

- The big cat pane no longer opens by itself when a session starts. Type `/cat` to open it, or turn on "Open the big cat pane on start" in settings.

## 1.0.0

First public release.

- 18 characters: 8 cats, 9 space cats, and a songkok cat
- Moods (chill, vibe, headbang, spin, shuffle, play, nap) with a Relaxed, Normal, or Party vibe
- 7 progress bar styles and lightsaber color themes
- Stat tiles, one line, minimal, and two-row layouts; Simple and Detailed modes
- 5-hour and weekly usage, reset countdown, context, reply time, model, and a usage forecast
- Red alert at 90%; at 100% the cat naps and the bar shows a lock with the time until reset
- Smart alerts at 75%, 90%, 100%, and on reset
- Today's stats in the cat pane
- Fewer redraws, so the strip doesn't blink
